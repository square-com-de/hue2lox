# Lamp icon research — 19 October 2026

Historical research snapshot from 19 October 2026; the early source registry then contained the original Hue Go. Current fresh installations start with an empty registry. Full live installation coverage was not established by this research. This update extends generic shapes and model-family assignments from the existing local model catalog. Manual overrides retain priority; no user-assigned lamp names are guessed from.

The drawings are independently constructed, simplified category symbols, not traced manufacturer artwork. No product photos or external SVG paths are shipped. Exact silhouette accuracy for each generation is not claimed. The model IDs come from the already attributed community catalog, not directly from official product photos. See catalog/lamp-icon-models.json for assignments and source notes. For example the ambiguous catalog entry LCL003 says “Lily outdoor led strip”; it is deliberately not classified as a Lily spotlight.

New categories: bollard, garden spotlight, wall lantern, lantern path light, floodlight, linear wall washer, round accent light, tilted accent light and compact light bar. Existing Signe models use the slim floor-light symbol. Go bowl and Go portable table lamp are different shapes and must not be conflated by family name.
