# Container base sources and notices / Container-Quellen und Lizenzen

## English

This bundle contains the corresponding upstream source archives, Alpine patches,
build/install recipes and original license/copyright notices for the pinned
Python/Alpine base used by Hue2Lox on linux/amd64 and linux/arm64. The base identity
is recorded in `provenance/base-image.json`. It is not an image release.

`component-map.json` and `NOTICES.md` map the runtime packages, Python, pip and
pip's vendored libraries to the included files. `SHA256SUMS.txt` verifies the
bundle contents. Original source archives retain notices that appear in individual
source headers. Standard MIT, MPL-2.0 and GPL-2.0 texts supplement upstream
references; copyright holders are not invented where upstream provides none.
The Alpine release and Kerberos configuration payloads are generated by the
included APKBUILDs. Public Alpine signing keys and their installation recipes are
included unchanged. The virtual `.python-rundeps` record has no separate payload.

The exact official Python image Dockerfile and its license are in `supplements/`.
The Alpine `recipes/` directories contain the package build configuration, patches
and installation hooks. Sources are in `sources/`. Python's build configuration
is also recorded by the base image Dockerfile. Rebuilding requires the relevant
Alpine build environment and its normal toolchain; this archive is not an offline
build environment. Do not execute downloaded build recipes just to read notices.

Hue2Lox's own source, LICENSE, NOTICE, THIRD-PARTY-NOTICES and catalog notices
remain in the matching application release/source archive. This base bundle does
not change the previously documented handling of the Hue CA certificates.

### Producing the bundle from the repository

Run `python3 scripts/build-source-bundle.py --output /tmp/hue2lox-base-sources`.
Choose a new output directory. Every download is checked against the committed
lock files. The script creates a tar.gz, an outer SHA256 checksum and an internal
file checksum list. It refuses missing inputs and incomplete component mappings.

### Delivery with a future image release

Upload the archive and checksum as permanent assets beside the matching image
release, together with the application source and per-platform image digests.
Link them from the registry description and release notes. Verify anonymous
access before enabling the image publication step. Keep the source assets
available for as long as the corresponding image is offered; retain an additional
archived copy. Do not substitute expiring CI artifacts or upstream links for the
recipient-facing download. This uses direct source delivery, not a written offer.

## Deutsch

Die Beilage enthält die zur festgeschriebenen Container-Basis gehörenden Quellen,
Patches, Bau- und Installationsdateien sowie Lizenz- und Copyrighttexte für AMD64
und ARM64. Die Zuordnung steht in `component-map.json` und `NOTICES.md`; alle
Dateien sind über `SHA256SUMS.txt` prüfbar. Auch Python, pip und die darin
enthaltenen Bibliotheken sind erfasst. Copyrightangaben werden unverändert aus
den Originalen übernommen; fehlende Urheberangaben werden nicht erfunden.

Der oben genannte Befehl erzeugt das Archiv erneut und prüft alle Downloads.
Die Beilage ist noch keine Image-Veröffentlichung. Beim ersten Image-Release
werden Archiv und Prüfsumme dauerhaft neben dem passenden Hue2Lox-Quellcode
veröffentlicht und von der Registry aus verlinkt. Befristete CI-Artefakte ersetzen
diesen Download nicht. RC3 und laufende Installationen bleiben unverändert.
