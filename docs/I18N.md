# Interface languages

Deutsch and English are bundled offline. Source dictionaries: `web/locales/de.json` and `en.json`. German source phrases are message keys, including a small number of sentence fragments for existing counters. After editing, run `python3 tools/build_locales.py`; commit the generated `.js` files too. No translation service or new package is required.

At first load, the first supported browser language wins (de-* or en-*); otherwise English. A valid stored preference overrides detection. Storage failures are caught, so the interface still loads. The selector is available at login and in the header. Switching reloads the current page and preserves the server login cookie; unsaved inputs and temporary selections reset. Saved lamp usage is unaffected.

Static markup is translated once before application scripts insert dynamic data. Dynamic interface literals explicitly use `t()`. Device/room/bridge/product names are not passed through general DOM translation; unknown messages fall back to German. Date/number formatting uses the selected locale. No HTML is inserted from translated values.

Technical payloads, paths, token placeholder, literal header separator `\r\n`, identifiers and user names remain unchanged. XML requests optionally supply `language: "de" | "en"`; only generated command labels and bulk output labels change. Omitted language preserves previous German exports. Unknown language values are rejected.

Tutorial sources: TUTORIAL.de.md and TUTORIAL.md. Build with `python3 tools/build_tutorial.py` and `python3 tools/build_tutorial.py --english`. Routes `/tutorial` and `/tutorial/en`. Screenshots still show the German interface and are labeled accordingly in the English guide. Licenses page is bilingual; upstream license texts are retained verbatim.

Tests: `tests/test_i18n.py` covers language detection/fallback, dictionary parity/build output, static asset routes and XML protocol/name preservation. `tests/test_header_format.py` continues to verify actual clipboard helper and XML header bytes. See TEST-RESULTS.md for browser checks.
