# Hue2Lox 1.0.1 — Stable

[Release and downloads / Release und Downloads](https://github.com/square-com-de/hue2lox/releases/tag/v1.0.1) · [Release notes / Hinweise](docs/RELEASE-NOTES-1.0.1.md) · [English installation](INSTALL.md) · [Deutsche Installation](INSTALL.de.md)

The first stable release includes scene on/off control, the shared installer and local discovery help. Native deployment remains experimental and amd64-only. See the release notes for tested scope, update instructions and limits.

Das erste stabile Release enthält Szenen-Ein/Aus, den gemeinsamen Installer und lokale Suchhilfen. Nativ bleibt experimentell und auf amd64 beschränkt. Geprüfter Umfang, Update-Anleitungen und Grenzen stehen in den Release-Hinweisen.

Docker Hub: `docker.io/dubctrl/hue2lox:1.0.1` · GHCR: `ghcr.io/square-com-de/hue2lox:1.0.1` (AMD64/ARM64). Prefer a fixed version. / Eine feste Version bevorzugen.
